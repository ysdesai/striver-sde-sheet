# Solutions

One folder per topic, one file per problem. To scaffold a problem from the repo root:

```bash
python scripts/new.py 37          # by sheet number
python scripts/new.py two-sum     # or by slug
```

Each file has a docstring for the approach, complexity, and the mistakes you made, followed by a `class Solution` stub you can paste into LeetCode.
After you push, the README's **Code** column links to the file.
